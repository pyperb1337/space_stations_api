# API каталога космических станций

Учебный проект на FastAPI с использованием Pydantic-моделей для валидации входящих данных и обработки POST-запросов.

## Эндпоинты и модели
- `GET /stations` — возвращает список всех космических станций с использованием модели ответа `Station`[cite: 23, 25].
- `POST /stations` — создает новую станцию, принимая данные через модель `StationCreate` и возвращая статус 201[cite: 23, 25].
